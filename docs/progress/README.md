# Daily progress logs

This directory records dated development progress for Rococo Outreach.

## Naming convention

- Use `YYYY-MM-DD.md` for one daily log.
- Record decisions, verification results, deployment evidence, blockers, and next actions.
- Never record passwords, authorization codes, API tokens, cookies, full message bodies, or secret-bearing screenshots.
- Keep durable product requirements and implementation plans in their respective `docs/product`, `docs/operations`, and `docs/superpowers/plans` documents; use daily logs for dated execution evidence.
