# 2026-08-10

## 联系人 CSV 导入和批量选择

- Added `POST /api/contacts/import` with `preview` and `commit` modes.
- Added CSV parsing for quoted fields, UTF-8 BOM, CRLF, header aliases, tags, and contact statuses.
- Required `email`; supported optional `displayName`, `salutation`, `language`, `company`, `mediaName`, `role`, `country`, `tags`, `notes`, and `status` columns.
- Added validation limits: maximum 1 MB per CSV and 500 rows per import; duplicate emails and invalid statuses are rejected before commit.
- Commit mode upserts by normalized email, so re-importing the same contact updates it instead of creating a duplicate.
- Added Contacts UI CSV preview with valid-row/error counts and an explicit import confirmation button.
- Added contact checkboxes, select-visible, and “Add selected to Campaign”; blocked or blank-email contacts cannot be bulk selected.
- Selected contacts are converted into recipient rows, while duplicate emails already in the Campaign are skipped.
- Local production build passed and route `/api/contacts/import` was included in the Next.js route table.
- Deployed commit `2066f30` (`Add contact CSV import and bulk campaign selection`).
- Post-deploy preview smoke test returned `200` with one normalized valid row and semicolon-separated tags.
- Invalid CSV preview returned validation issues; invalid commit returned `422` and did not create the preview contact.
- No contacts were committed during smoke testing and no email was sent.

### Status/tag filtering

- Added combined keyword, status, and tag filters to the Contacts panel.
- Added a status selector (`all`, `active`, `inactive`, `blocked`) and a tag selector sourced from the loaded contact library.
- “Select visible” now selects only contacts matching the current search and filters.
- Existing safety rules remain: blank-email and blocked contacts cannot be selected for Campaigns.
- Local production build passed after the filter change.
- Deployed commit `9ea1b85` (`Add contact status and tag filters`).
- Post-deploy checks returned `200` for `/api/contacts`, `/api/campaigns`, and CSV preview; unauthenticated Campaign send remained `401`.
- No contacts were committed and no email was sent.
