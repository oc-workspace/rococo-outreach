## Persistent mailbox account foundation

- Added `EmailMailboxAccount` persistence with workspace key, provider, SMTP connection metadata, active status, verification status, and verified timestamp.
- Linked `EmailSender` records to mailbox accounts and migrated `winnie@next2p.com` to the verified development mailbox account.
- Campaign creation and failed-delivery retry now require an active, verified mailbox account whose mailbox email, SMTP host, port, and TLS mode match the connected SMTP configuration.
- The queue worker only claims deliveries whose sender is linked to an active, verified mailbox account. SMTP passwords remain outside PostgreSQL.
- Added mailbox account unit coverage and an E2E sender fixture proving an unlinked `next2p.com` sender is not exposed.
- Verification: 12/12 unit tests, production build passed, isolated E2E passed 13/13, and all 13 migrations applied successfully with simulated mail transport. No real SMTP or real email send was used.
